# TeX-it - Hack Days in the 6ix#
#### TeX-it is a native AI-powered LaTeX IDE that makes technical writing faster and more intuitive. It allows users to write documents using voice, uploaded files, or images of handwritten content. Using Deepgram speech-to-text, users can dictate ideas or commands and instantly convert them into structured LaTeX. Users can also upload images of handwritten or printed notes, and Gemini converts them into valid LaTeX. Edits can be described in natural language, and the system generates the correct LaTeX automatically. The application is built with React, Electron, TypeScript, and a Go backend.
